# Pandas Basics

Practice notebooks covering core Pandas operations for data manipulation and analysis.

## Topics Covered

- Series and DataFrame creation
- Indexing, slicing, and filtering
- GroupBy, aggregation, and pivot tables
- Merging, joining, and reshaping DataFrames
- Handling missing values
- Reading/writing CSV and Excel files

## Tech Stack

Python, Pandas, Jupyter Notebook

## Run

```bash
pip install pandas jupyter
jupyter notebook
```
